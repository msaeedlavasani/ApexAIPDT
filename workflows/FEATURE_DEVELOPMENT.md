# Feature Development Workflow

## 1. Understand

Translate the request into user outcome, scope, acceptance criteria, and affected domains.

## 2. Classify

Identify task class, risk, required brains, and autonomy mode.

## 3. Targeted discovery

Read only the relevant project rules, registries, closest analogue, dependencies, and tests.

## 4. Reuse analysis

Search in this order:

reuse → compose → extend → create.

## 5. Impact analysis

Identify product, design, architecture, data, security, operations, and asset impacts.

## 6. Plan

Produce a Feature Contract. For autonomous work, this plan may be generated internally before execution.

## 7. Human boundary check

Escalate only decisions that cannot be discovered, inferred, or decided within authority.

## 8. Implement

Execute the approved/internal plan without unrelated redesign.

## 9. Validate

Run the smallest sufficient validation set, increasing scope when risk or evidence requires it.

## 10. Learn

Capture durable decisions, new reusable patterns, asset requirements, and recurring failure modes.

## 11. Report

Return:

- implemented;
- reused;
- created;
- validation;
- assets required;
- decisions made;
- risks;
- human input required.
