# Release Workflow

## Pre-release

- product acceptance criteria verified;
- relevant quality gates passed;
- analytics instrumentation verified;
- security/operational checks completed where applicable;
- unresolved risks documented.

## Release decision

The Orchestrator compiles evidence. Human approval is required if the project constitution protects release approval or if material unresolved product/business risk remains.

## Post-release

- monitor reliability;
- verify key analytics;
- observe errors and user behavior;
- compare against success metrics;
- record learnings;
- promote validated learnings into project memory.

Release is not the end of the product loop. It begins the measurement phase.
