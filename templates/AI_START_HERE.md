# AI Start Here

This file is generated into every APDT-managed project and is the first navigation document for AI agents.

## Mandatory entry protocol

Never jump directly from user request to production code for non-trivial work.

REQUEST → CLASSIFY → ROUTE CONTEXT → FIND ANALOGUE → PLAN → IMPLEMENT → VALIDATE → REPORT

## First reads

1. this file;
2. project constitution;
3. project context map;
4. project-specific agent instructions, if present.

Then read only task-relevant sources.

## Context rule

Do not read the entire repository by default. Use targeted discovery and minimum sufficient context.

## Reuse rule

reuse → compose → extend → create.

## Human rule

Do not ask questions answerable from the repository, constitution, registries, or established patterns. Escalate only genuine product/design/architecture/business decisions or missing external inputs.

## Completion rule

Never claim completion without relevant validation evidence.

## Final report

Return:

- implemented;
- reused;
- created;
- assets required;
- validation;
- decisions;
- risks;
- human input required.
